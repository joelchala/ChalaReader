ChalaReader: Lectura limpia y privada en Manifest V3

ChalaReader forma parte de la Suite Chala junto a Chalablock, ChalaVPN, ChalaTabs y ChalaDev. Su objetivo es aislar el contenido principal de cualquier artículo web dentro de un Shadow DOM limpio y libre de rastreadores.

Arquitectura local y permisos mínimos

La extensión utiliza únicamente los permisos activeTab, scripting y storage. Al hacer clic en el icono o pulsar Alt+R, valida que la pestaña actual no pertenezca a una ruta interna protegida e inyecta el motor de extracción de forma idempotente.

«El usuario decide cómo leer la web sin ruido visual, rastreadores ni distracciones.»

Exportación y lectura offline

Desde la barra flotante puedes cambiar al instante entre los temas Oscuro Chala, Sepia y Claro, ajustar tipografía, ancho de columna entre 60ch y 85ch, exportar el texto limpio a Markdown (.md), imprimir un PDF limpio o guardar artículos para leer luego en almacenamiento local.

  • Código fuente de la extensión: src/
  • Compilación desempaquetada: dist/build/ChalaReader.chromium/
  • Pruebas automatizadas: node tests/verify.mjs

Barra lateral de ejemplo

Este bloque lateral actúa como elemento auxiliar que ChalaReader descarta automáticamente al activar el modo lectura con Alt+R.
